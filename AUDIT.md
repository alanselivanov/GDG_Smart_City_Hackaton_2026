# Аудит backend Astana Walks

Дата аудита: 18 октября 2026 года. Основание: ТЗ хакатона «ИИ-помощник по прогулкам в городе Астана» и запрос на backend Python/FastAPI с двумя stretch goals — группа 3–5 человек и ответы на языке пользователя. Аудит относится к коду этого репозитория и локальному снимку OSM. Документ фиксирует как реализованное поведение, так и известные ограничения.

## 1. Краткий вывод

Backend работает: автоматизирован сбор реальных POI из OpenStreetMap через Overpass, REST API выдаёт индивидуальные и групповые рекомендации, ответ содержит ссылку на источник, примерное время пешком, длительность посещения, краткое объяснение и действие. Для русского, казахского и английского языков есть локализованные тексты. Локальный SQLite-снимок после последнего сбора содержал **1 359 POI**. Ручной запуск Uvicorn и HTTP-запросы прошли; `pytest` завершился с **7 passed**.

Граница реализации RAG: поиск опирается на реальные POI, географию, категории и словарь намерений. Без LLM-ключа текст создаётся проверяемыми шаблонами. Интеграция с OpenAI-совместимым Chat Completions API реализована и проверена на контролируемом HTTP-ответе, но реальный провайдер без предоставленного ключа не проверялся. Семантического векторного поиска нет.

## 2. Соответствие требованиям

| Требование | Статус | Как работает / граница |
|---|---|---|
| Реальные POI Астаны и автоматизированный сбор | Выполнено | `app/ingest.py` запрашивает Overpass; ручная команда, фоновое обновление и защищённый HTTP endpoint. |
| Название, координаты, описание, категория, часы, контакты | Выполнено при наличии данных | Поля берутся из OSM. Если поле отсутствует, возвращается `null`; оно не выдумывается. Рейтинг/популярность не выводятся, так как подходящих данных в источнике нет. |
| Рекомендации по месту, предпочтениям и контексту | Выполнено с ограничением | Учитываются координаты, категории, интересы, словарь ключевых слов, временной бюджет и известные часы. Произвольный текст понимается эвристически. |
| 1–3 конкретных места, почему, время, что делать | Выполнено | Ответ связан с OSM ID/URL и содержит `why`, `visit_minutes`, `walking_minutes`, `what_to_do`. |
| Понятный источник и степень уверенности | Выполнено | `source_url`, `fetched_at`, `open_status`, `notices`, `text_source`, `generated_with`. Неизвестные часы не объявляются «открыто сейчас». |
| Приватность точной локации | Выполнено на уровне приложения | Координаты и запросы пользователя не сохраняются в SQLite и не передаются в LLM. Логи внешнего прокси не контролируются этим кодом. |
| Группы 3–5 | Выполнено | Отдельный endpoint; времена пешком и интересы каждого участника, время встречи и конца одного посещения. |
| Язык пользователя | Выполнено для `ru`, `kk`, `en` | Локализованы объяснения, действия и предупреждения. Собственное название POI остаётся на исходном языке, если перевода нет в OSM. |
| Остальные stretch goals | Не реализованы по запросу | Нет последовательного мини-маршрута, локальных событий и режима доступности. |
| Frontend, слайды и видео | Вне этого backend | REST API и Swagger UI готовы для подключения frontend; отдельные материалы сдачи не создавались. |

### Сбор данных

- Источник — OSM `node`, `way`, `relation` в ограничивающем прямоугольнике `50.98,71.20,51.32,71.68`, включая район аэропорта. Выбраны релевантные теги: кафе, еда, музеи, культура, парки, детские площадки, достопримечательности, вечерние и некоторые активные места. Это не все POI города.
- Для площадных объектов используется центр OSM-геометрии. Неназванные детские площадки получают родовое название, но сохраняют собственные координаты и OSM ID.
- Ответ Overpass с ошибкой, пустой или резко уменьшившийся снимок отвергается. Запись новых объектов и удаление отсутствующих в полном снимке происходят в одной транзакции: сбой не уничтожает старый кэш.
- `AUTO_REFRESH=true` включает фоновую проверку раз в час; обычный интервал успешного сбора — 24 часа. Ручной запуск: `python -m app.ingest`. Публичный Overpass не вызывается для каждого пользовательского запроса.
- В таблице `pois` хранятся имена, категория, координаты, допустимые теги, описание, часы, сайт, телефон, OSM URL и время загрузки. `sync_state` хранит время и объём последнего успешного сбора.

## 4. REST API

OpenAPI: `/openapi.json`, интерактивный интерфейс: `/docs`.

| Метод и путь | Назначение |
|---|---|
| `GET /health` | Состояние, число POI, последняя синхронизация и ошибка обновления. Статус `awaiting_poi` возвращается с HTTP 200, поэтому это не строгий readiness probe. |
| `GET /v1/pois` | POI рядом с `lat`/`lon`, радиус, категория, язык, лимит. |
| `GET /v1/pois/search` | Поиск ориентира по названию, например Mega Silk Way. |
| `POST /v1/recommendations` | До трёх личных рекомендаций. |
| `POST /v1/group/recommendations` | До трёх альтернатив для группы из 3–5 человек. Каждая альтернатива — одно общее место. |
| `POST /v1/admin/refresh` | Обновление POI по заголовку `X-Admin-Token`. |

Pydantic проверяет координаты в зоне Большой Астаны, длину текста до 500 символов, бюджет 20–360 минут, максимум 3 рекомендации, 3–5 участников, допустимые категории и языки, дату начала с часовым поясом и конфликтующие фильтры. Лишние JSON-поля запрещены. Если бюджет не передан, выражения вроде «30–60 минут» или «2 часа» распознаются простым правилом; иначе бюджет 90 минут. `starts_at` не может быть более чем на 7 дней в будущем.

Основные HTTP-ошибки: `422` для невалидного ввода, `503` при пустой базе или отключённом admin endpoint, `401` при неверном токене, `409` при одновременном обновлении внутри процесса, `502` при неудачной загрузке Overpass. При недоступной LLM рекомендации продолжают работать на шаблонах.

Ответ включает `context_used` с применёнными фильтрами, интересами и методом оценки расстояния; источник `© OpenStreetMap contributors (ODbL)` и ссылку на лицензию; для каждого места — OSM URL. `generated_with` различает `grounded_templates` и `llm`; `text_source=generated_from_poi` отделяет предложенное действие от исходных данных POI.

## 5. Поиск, часы и планирование

1. Намерение определяется по словарю русских, казахских и английских слов (кофе, прогулка, дети, культура, вечер и др.) и явным фильтрам. Это не универсальная NLP-модель; незнакомая формулировка может свестись к ближайшим POI.
2. Расстояние считается по дуге большого круга. Оценка ходьбы: `ceil(расстояние × 1,25 / 75 м/мин)`. Расстояние в ответе остаётся расстоянием по прямой. Ни дорожная сеть, ни переходы, ни входы в здания не рассчитываются.
3. POI исключается, если оценка пути превышает лимит или не оставляет хотя бы 15 минут визита. Стандартное время визита зависит от категории и ограничивается оставшимся бюджетом.
4. `opening_hours` уверенно обрабатывает `24/7` и простые недельные интервалы, включая переход через полночь. Сложные правила, праздники и отсутствующие часы обозначаются `unknown`; достоверно закрытые по распознанному расписанию места исключаются. Даже статус `open` зависит от актуальности OSM.
5. Баллы учитывают совпадение запроса и интересов, близость, групповую совместимость, известные часы и полноту записи. Повторяющиеся OSM-объекты с одинаковым названием в радиусе 80 м не выводятся дважды.
6. Для группы оцениваются все участники; `group_meeting_at` определяется временем прибытия самого удалённого участника. Возвращаются массивы пешего времени и совпадения интересов в порядке участников входного JSON. `group_ends_at` — оценка окончания посещения **одного** места, не маршрут из нескольких мест и не бронь.

Запрос о розетках не превращает отсутствие тега в подтверждение розетки: текущие рекомендации показывают кафе с предупреждением, что удобство надо уточнить. Тишина также не подтверждается OSM. Для ситуации перед вылетом допускаются близкие кафе/еда и добавляется предупреждение оставить запас на дорогу, регистрацию и досмотр.

### Генерация и языки

По умолчанию `why`, `what_to_do`, предупреждения и причины неопределённых часов формируются на `ru`, `kk` или `en`. Тексты основаны на категории, дистанции, интересах и подтверждённых тегах. Если нужного локализованного описания нет в OSM, поле `description` может быть `null`.

Если указан `LLM_API_KEY`, в совместимый `/chat/completions` передаются только факты о **уже найденных** POI: ID, имя, категория, оценки времени/расстояния и исходные часы. Сырой запрос и координаты пользователей не передаются. Код принимает только JSON с ожидаемыми ID и ограниченными текстами, иначе возвращается к шаблонам. Это структурная, но не полноценная семантическая проверка фактов: LLM всё ещё может добавить неподтверждённое утверждение. Запрос к реальному провайдеру не проверялся.

## 6. Безопасность, приватность и эксплуатация

- Admin endpoint выключен без `ADMIN_TOKEN`; сравнение настроенного токена использует `hmac.compare_digest`. CORS допускает только явно перечисленные origins.
- Координаты, интересы и текст запроса обрабатываются в памяти запроса и не пишутся в SQLite. Параметры внешнего reverse proxy и его логи не контролируются приложением.
- Входящие данные ограничены Pydantic, SQL-запросы используют параметры, URL сайта POI допускает только HTTP(S). OSM-названия и описания остаются внешним недоверенным текстом; frontend должен экранировать их при выводе.
- На ответы Overpass 406/429 предусмотрена пауза 30 секунд; старый снимок остаётся доступен при ошибке источника. Публичный источник имеет квоты и не подходит для бесконтрольного масштабирования.
- Встроенных учётных записей, rate limiting публичных read-endpoints, TLS-терминации, распределённой блокировки обновлений, метрик и резервного копирования нет. Их следует добавить в инфраструктуре перед публичной нагрузкой.
- Открытость места, шум, розетки, интерактивы и события не утверждаются без достоверной записи. Атрибуция OSM/ODbL включена в API; при публичном отображении она должна остаться видимой.

## 7. Проверки

`python -m pytest -q` → **7 passed**, одно предупреждение о совместимости `fastapi.testclient`/Starlette с текущим `httpx`; оно не привело к сбою. Тесты охватывают разбор/защиту снимка Overpass, замену кэша, переход часов через полночь, индивидуальный API и локализацию, извлечение бюджета из текста, группу 3–5 и валидацию, защиту admin endpoint и контракт LLM без отправки пользовательских координат/текста.

Ручной HTTP smoke test проводился на запущенном Uvicorn: `/health` вернул `ready` и 1 359 POI, поиск нашёл Mega Silk Way, индивидуальный и групповой POST вернули HTTP 200 с реальными OSM POI. Сервер после проверки остановлен. Реальный сбор `python -m app.ingest` завершился успешно.

**Не проверены:** реальный ответ внешней LLM с рабочим ключом; нагрузочное и длительное выполнение; актуальность каждого объекта OSM; точность уличного пути; эксплуатация за reverse proxy и при нескольких процессах; качество на широком наборе естественных запросов.

## 8. Остаточные риски и следующие шаги

1. Для презентации именно LLM-RAG задать ключ в `.env`, выполнить сквозной тест с настоящей моделью и проверить фактические утверждения в ответах. Без ключа работает retrieval + шаблонная генерация.
2. Для строгого ограничения времени подключить маршрутизатор по пешеходной сети и проверять реальные пути лучших кандидатов.
3. Для сценариев «тихое кафе с розеткой», интерактивный музей и актуальные часы нужен дополнительный проверенный источник: OSM сейчас почти не содержит этих свойств.
4. Для более сложных запросов заменить словарные эвристики семантическим поиском/переранжированием и измерять качество на наборе сценариев.
5. Для публичного сервиса добавить rate limiting, TLS/reverse proxy, метрики, резервное копирование и отдельный процесс обновления; при большем датасете — пространственный индекс вместо чтения всех POI из SQLite на запрос.

## 9. Воспроизведение

```powershell
python -m venv .venv
.venv\Scripts\Activate.ps1
python -m pip install -r requirements-dev.txt
Copy-Item .env.example .env
# В .env указать свой контакт в OVERPASS_USER_AGENT
python -m app.ingest
python -m pytest -q
python -m uvicorn app.main:app --host 127.0.0.1 --port 8000
```

После запуска: `http://127.0.0.1:8000/docs` и `http://127.0.0.1:8000/health`. Overpass не требует API-ключа; для необязательной LLM-интеграции ключ создаётся в [OpenAI Platform](https://platform.openai.com/api-keys) или задаётся совместимый сервис через `LLM_BASE_URL`. [Полные инструкции и примеры JSON](README.md). Лицензия данных — [OpenStreetMap/ODbL](https://www.openstreetmap.org/copyright).
